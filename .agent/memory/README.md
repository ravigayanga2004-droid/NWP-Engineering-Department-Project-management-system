# Session memory

One file per member, written by `/remember save` and read by `/remember restore`:

- `member-1.md` – Auth, access & app shell
- `member-2.md` – Reference data & register
- `member-3.md` – Estimate workflow
- `member-4.md` – Works list, import & DevOps

Each file holds only the latest session. Never write in another member's file. Never store secrets, `.env` values or real department data here.
